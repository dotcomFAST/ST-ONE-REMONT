# ST ONE REMONT — лендинг

Концепт односторінкового сайту для ремонтної компанії ST ONE REMONT (Київ та область).
Статичний сайт: HTML + CSS + JavaScript, без збірки та залежностей.

## Структура

```
index.html       — сторінка
css/style.css    — стилі (2 шрифти: Cormorant Garamond та Onest, Google Fonts)
js/prices.js     — прайс: категорії, позиції, 6 ключових цін (TOP)
js/main.js       — фільтр портфоліо, лайтбокс, слайдер «до/після», пошук у прайсі, форма
img/             — фото робіт
robots.txt       — забороняє індексацію (концепт)
```

## Запуск

Відкрити `index.html` у браузері. Сервер не потрібен.

## Як оновити прайс

Усі ціни в `js/prices.js`. Кожна позиція: `['Назва', ціна, 'одиниця']`,
а четвертий елемент `1` додає «від» перед ціною:

```js
['Укладання широкоформатної плитки більше 120×120', 2000, 'м²', 1]
```

## Перед запуском для клієнта

- [ ] Замінити фото в `img/` на оригінали (зараз — вирізки зі скріншотів Instagram).
- [ ] Пара «до/після» в одному об'єкті (`before_s4.jpg` / `living_bright.jpg` — різні об'єкти).
- [ ] Узгодити з клієнтом одиниці в прайсі (унітаз, інсталяція, фільтр грубої очистки — зараз грн/м²).
- [ ] Перевірити тексти-обіцянки: «передзвонюємо того ж дня», «звіти в месенджер».
- [ ] Підключити відправку форми в Telegram через серверну функцію. Токен бота не можна класти у фронтенд.
- [ ] Прибрати `noindex` у `index.html` і змінити `robots.txt` на дозвіл індексації.
- [ ] Прибрати верхню стрічку «Концепт лендингу…».
